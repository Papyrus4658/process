# LAMP環境構築
- Linux
- Apache
- MySQL(or MariaDB)
- PHP

上記4つを組み合わせた開発環境のことを、頭文字を取って"LAMP"と呼ぶそうです。

今回は、そのLAMP環境を学習/検証用として、仮想マシンで構築してみました。

## 実行環境
- Rocky Linux 10.2(VirtualBox)
- Apache 2.4.63
- MariaDB 15.1
- PHP 8.3.33

### MariaDB初期設定
最初に、mariadb-secure-installationを実行します。
```bash
[lampuser@localhost ~]$ sudo mariadb-secure-installation
```

Unix Socket認証に切り替えるかを訊かれる。

```bash
Switch to unix_socket authentication [Y/n] y
Enabled successfully!
Reloading privilege tables..
 ... Success!
```
調べてみたところ、OSとDBのユーザー名が一致していれば、パスワード無しでログインできる仕組みのようです。

rootパスワードを変更します。
```bash
Change the root password? [Y/n] y
New password: 
Re-enter new password: 
Password updated successfully!
Reloading privilege tables..
 ... Success!
```

匿名ユーザー(パスワード無しでログインできるユーザー)を削除します。
```bash
Remove anonymous users? [Y/n] y
 ... Success!
```

rootユーザーのリモートログインを無効化します。
```bash
Disallow root login remotely? [Y/n] y
 ... Success!
```

testデータベース（全てのユーザーがアクセス可能）を削除します。
```bash
Remove test database and access to it? [Y/n] y
 - Dropping test database...
 ... Success!
 - Removing privileges on test database...
 ... Success!
```

最後に、権限テーブルをリロードするか訊かれるので、実行したら終了です。
```bash
Reload privilege tables now? [Y/n] y
 ... Success!

Cleaning up...

All done!  If you've completed all of the above steps, your MariaDB
installation should now be secure.

Thanks for using MariaDB!
[lampuser@localhost ~]$ 
```

rootユーザーでログインします。
```bash
[lampuser@localhost ~]$ sudo mysql
[sudo] lampuser のパスワード:
Welcome to the MariaDB monitor.  Commands end with ; or \g.
Your MariaDB connection id is 3
Server version: 10.11.18-MariaDB MariaDB Server

Copyright (c) 2000, 2018, Oracle, MariaDB Corporation Ab and others.

Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

MariaDB [(none)]> 
```
確かに、パスワード無しでログインできています。

### データベース接続
MariaDBに接続するPHPファイルを作成します。
```bash
[lampuser@localhost ~]$ sudo vi /var/www/html/dbconnect.php 
[lampuser@localhost ~]$ cat /var/www/html/dbconnect.php 
<?php
$db="mysql:host=localhost;dbname=testdb1;charset=utf8mb4";
$user="testuser1";
$pass="testpassword";

try{
        $pdo=new PDO(
                $db,$user,$pass,[PDO::ATTR_ERRMODE=>pdo::ERRMODE_EXCEPTION]
        );

        echo "データベース接続成功<br>";

        $stmt=$pdo->query("select * from testtable1");

        foreach ($stmt as $row) {
                echo "ID: " . $row["id"] . " - 名前: " . $row["name"] . "\t";
        }
}catch(PDException $e){
        echo "データベース接続失敗";
}
?>
[lampuser@localhost ~]$ 
```

再度アクセスします。
![db接続の成功を確認]({{screenshots}}/{{id}}/success_dbconnect.png)
成功しました。先程登録したデータが表示されています。
