# Raspberry Piのインストールと初期設定
Raspberry Piを使い始めるまでに必要な手順をまとめました。

1. 組み立て
2. Raspberry Pi Imagerのインストール
3. microSDにRaspberry Pi OSをインストール
4. Raspberry Piの起動
5. SSHで接続

## 環境
- Raspberry Pi 5(メモリ1GB)
- Pi 5用ケース（公式）
- ACアダプタ（非公式）

学習用に、入ったお店で一番安いものを購入しました。

節約の為に、キーボードもモニターも買っていません。

ACアダプタが非公式なのも、少し安かったからです。

性能は同等とのことなので問題無いと思われます。

## Raspberry Pi起動
書き込みが完了したmicroSDをラズパイ本体に挿入。
![microSD挿入]({{screenshots}}/{{id}}/insert_microsd.jpg)

ACアダプタを繋ぐと電源ランプが緑色に点滅する。

初回起動のためか少し時間がかかる（5分くらい）。

正常に起動できたなら、緑色に点灯する。

## PCからSSHで接続
LAN内のssh接続可能な機器を検索。
```zsh
roguesarch% nmap -p 22 --open 192.168.11.0/24 
Starting Nmap 7.991 ( https://nmap.org ) at 2026-09-20 09:39 +0900
Nmap scan report for 192.168.11.31
Host is up (0.0065s latency).

PORT   STATE SERVICE
22/tcp open  ssh

Nmap done: 256 IP addresses (6 hosts up) scanned in 10.65 seconds
roguesarch%     
```
見つかりました。

ssh <ユーザー名>@<IPアドレス>と入力して接続を試みる。
```zsh
roguesarch% ssh rpi5user@192.168.11.31
```

接続を続けるか訊かれるので、
```zsh
Are you sure you want to continue connecting (yes/no/[fingerprint])? 
```
"yes"と入力。

今度はパスワードの入力を求められるので、
```zsh
rpi5user@192.168.11.31's password: 
```
先程設定したものを入力。

```zsh
rpi5user@192.168.11.31's password: 
Linux raspberrypi5 6.18.50+rpt-rpi-2712 #1 SMP PREEMPT Debian 1:6.18.50-1+rpt1 (2026-09-11) aarch64

The programs included with the Debian GNU/Linux system are free software;
the exact distribution terms for each program are described in the
individual files in /usr/share/doc/*/copyright.

Debian GNU/Linux comes with ABSOLUTELY NO WARRANTY, to the extent
permitted by applicable law.
Last login: Sun Sep 20 00:24:39 2026 from fe80::85b2:ced0:aa39:ecba%wlan0
rpi5user@raspberrypi5:~ $ 
```
接続成功。

### 無線で接続できない場合
LANケーブルで繋いでから<ユーザー名>@<ホストネーム>.localと入力。
